# Auto-Update Setup Guide

This guide explains how to set up automatic updates for LivesportClaude using Google Drive.

## Overview

LivesportClaude uses [Sparkle](https://sparkle-project.org/) framework for automatic updates. The app checks for updates every 24 hours and can also be manually triggered from the menu.

## Google Drive Setup

### 1. Create Appcast File

1. Download `appcast.xml` from GitHub Actions artifacts
2. Upload it to Google Drive
3. Right-click → "Get link" → "Anyone with the link can view"
4. Copy the FILE_ID from the URL

Example URL: `https://drive.google.com/file/d/1ABC...XYZ/view`
FILE_ID is: `1ABC...XYZ`

### 2. Upload DMG Files

For each new version:

1. Download `LivesportClaude-X.X.X.dmg` from GitHub Actions artifacts
2. Upload to Google Drive
3. Get shareable link with "Anyone with the link can view"
4. Copy the FILE_ID

### 3. Configure the App

Update `LivesportClaude/LivesportClaude/Models/UpdateConfiguration.swift`:

```swift
static let appcastFeedURL = "https://drive.google.com/uc?export=download&id=YOUR_APPCAST_FILE_ID"
```

Replace `YOUR_APPCAST_FILE_ID` with the actual FILE_ID from step 1.

### 4. Update Appcast.xml

Each time you release a new version, update the appcast.xml on Google Drive:

```xml
<enclosure
  url="https://drive.google.com/uc?export=download&id=YOUR_DMG_FILE_ID"
  length="FILE_SIZE_IN_BYTES"
  type="application/octet-stream"
  sparkle:edSignature="..." />
```

Replace:
- `YOUR_DMG_FILE_ID` with the DMG file ID from step 2
- `FILE_SIZE_IN_BYTES` with the actual DMG file size
- Update version numbers and description

## Direct Download URLs

Google Drive direct download format:
```
https://drive.google.com/uc?export=download&id=FILE_ID
```

This URL:
- Works for automatic downloads
- Doesn't require authentication for public files
- Is stable (FILE_ID never changes)

## Deployment Workflow

### For Each New Version:

1. **Build**: Push to `main` or `claude/**` branch
2. **Download Artifacts**:
   - `LivesportClaude-X.X.X.dmg`
   - `appcast.xml` (generated by CI/CD)
3. **Upload DMG**: Upload new DMG to Google Drive, get FILE_ID
4. **Update Appcast**:
   - Edit `appcast.xml`
   - Replace DMG URL with new FILE_ID
   - Update version, date, size, description
5. **Replace Appcast**: Upload updated `appcast.xml` to Google Drive (overwrites old one)

## Testing Updates

1. Install current version of the app
2. Update `appcast.xml` with higher version number
3. Upload to Google Drive
4. In app: `LivesportClaude` menu → `Check for Updates...`
5. Verify update dialog appears
6. Test download and installation

## Appcast.xml Structure

```xml
<?xml version="1.0" encoding="utf-8"?>
<rss version="2.0" xmlns:sparkle="http://www.andymatuschak.org/xml-namespaces/sparkle">
  <channel>
    <title>LivesportClaude Changelog</title>
    <item>
      <title>Version 1.0.1</title>
      <description><![CDATA[
        <h2>What's New</h2>
        <ul>
          <li>New feature 1</li>
          <li>Bug fix 2</li>
        </ul>
      ]]></description>
      <pubDate>Thu, 26 Dec 2024 12:00:00 +0000</pubDate>
      <sparkle:version>1.0.1</sparkle:version>
      <sparkle:shortVersionString>1.0.1</sparkle:shortVersionString>
      <enclosure
        url="https://drive.google.com/uc?export=download&id=DMG_FILE_ID"
        length="12345678"
        type="application/octet-stream" />
      <sparkle:minimumSystemVersion>14.0</sparkle:minimumSystemVersion>
    </item>
  </channel>
</rss>
```

## Multiple Versions

You can keep multiple `<item>` entries in appcast.xml for version history:

```xml
<channel>
  <item><!-- Version 1.0.2 --></item>
  <item><!-- Version 1.0.1 --></item>
  <item><!-- Version 1.0.0 --></item>
</channel>
```

Sparkle will always pick the highest version.

## Troubleshooting

### Update Check Fails

- Verify appcast.xml URL is correct
- Check file permissions on Google Drive (must be public)
- Test URL in browser: should download XML file
- Check console logs in app for errors

### Update Won't Download

- Verify DMG URL in appcast.xml
- Test DMG URL in browser: should download file
- Check DMG file size matches `length` attribute
- Ensure Google Drive sharing is enabled

### App Shows "No Updates Available"

- Version in appcast.xml must be higher than current app version
- Format: `1.0.1` > `1.0.0`
- Check `sparkle:version` and `CFBundleShortVersionString`

## Security Notes

- This setup uses public Google Drive links (no authentication)
- Suitable for internal company distribution
- For production: Consider code signing and notarization
- Sparkle supports EdDSA signatures (not implemented in this version)

## File ID Stability

**Important**: Google Drive FILE_IDs are stable:
- ✅ FILE_ID stays the same when you replace file content
- ✅ Perfect for appcast.xml (one permanent link)
- ❌ New DMG upload = new FILE_ID (expected)
